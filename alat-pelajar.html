EduApp v1.0 • Khadijah Grade Analytics Engine

EduApp v1.0 — Platform Analytics & Student Tools

EduApp v1.0 dirancang untuk memberdayakan pelajar SMA/K sederajat di seluruh Indonesia dalam mengelola data akademik secara mandiri, terukur, dan transparan. Melalui pendekatan rekayasa regresi linier dan integrasi passing grade resmi SNPMB, siswa dapat memahami peluang seleksi perguruan tinggi negeri secara objektif.

Q1: Apakah data nilai saya aman?

A: Sangat aman. Seluruh data dimasukkan tersimpan 100% secara lokal di browser kamu (localStorage) dan tidak dikirim ke server luar mana pun.

Q2: Dari mana sumber data keketatan PTN diperoleh?

A: Data daya tampung dan peminat dihimpun secara terintegrasi dari portal resmi SNPMB Kemendikbudristek.

Q3: Bagaimana fitur Simulasi OCR bekerja?

A: Fitur ini menggunakan pemroses data client-side untuk membaca sampel dokumen dan mengisi form secara otomatis sebagai bentuk demonstrasi sistem cerdas.

1
Step 1: Input atau Pindai Data Nilai

Buka menu Analisa Nilai, lalu ketikkan nilai akademikmu atau gunakan fitur pemindai/preset contoh rapor untuk mengisi data secara cepat.

2
Step 2: Pilih Target PTN & Program Studi

Tentukan universitas dan jurusan impian pada PTN Matchmaker untuk mengukur rasio keketatan dan peta persaingan.

3
Step 3: Tinjau Indeks Kesiapan

Sistem akan menganalisis tren perkembangan nilai serta menghitung Indeks Kesiapan Akademik kamu secara otomatis.

4
Step 4: Manfaatkan Alat Pelajar

Gunakan koleksi Student Tools (Pomodoro, Pembersih Teks, Generator Sitasi, Perencana Jadwal) untuk membantu tugas harianmu.

Indeks Kesiapan Akademik

Skor komposit (0–100%) yang menghitung gabungan tren nilai, bobot mata pelajaran pendukung, dan tingkat kompetisi jurusan.

Keketatan (%)

Persentase rasio daya tampung dibanding total peminat tahun sebelumnya. Semakin kecil angkanya, semakin tinggi tingkat persaingannya.

Matpel Pendukung

Mata pelajaran utama yang diprioritaskan sesuai ketentuan Kurikulum Merdeka untuk program studi tertentu.
